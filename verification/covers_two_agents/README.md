# Cover sizes for two agents (Section 3.1) and further audits

A family of allocations *covers* a class of market valuations if every valuation of the class makes some member market EF1.

* `src/n2_cover.py` — independent of `fd.py`/`cegar.py`. Decides covering by linear programs (strict failure conditions per
  "who envies" pattern, scaled to margin 1; a witness valuation is checked against the definition).
  * E0: validation of the LP test against direct evaluation on 40,000 sampled valuations.
  * E1: additive markets, two agents: a covering pair of subjectively SD-EF1 allocations on 600 random hard profiles (m = 8..13) and
    under an adversarial hill-climb.
  * E2: exact minimum cover of *all monotone valuations* by subjectively SD-EF1 allocations (hitting-set CEGAR), m = 7, 8.
  * E3: the reversal path of Theorem 3.1 is an exact cover and every member is necessary (m = 9..11).
  * E4: the eleven-good two-agent profile where the disjoint-defect route fails but a two-allocation cover exists.
  * E5: how often a covering pair lies on the reversal path.
* `src/audit_extra.py` — A: Proposition 3.4 by brute force (EF1 for the majority valuation iff the set is split evenly, m ≤ 8; exact
  set-cover minima for m = 4, 5, 6); B: the thirteen-good profile (block-compatible matchings, the three forms of the case analysis,
  3,888 → 206 → 0); C: the twelve-good disjoint-defect profile (1,080 / 58 / defect histogram / no disjoint pair / the stated pair covers); D: the ten-good profile of Appendix H (483 / 34 / defect histogram / the only disjoint type).

```sh
cd src
python n2_cover.py all      # E1-E5, writes ../results/n2_cover_experiments.json (about 8 minutes on 12 cores)
python n2_cover.py E0       # LP validation (about 4 minutes), merged into the same file
python audit_extra.py all   # writes ../results/audit_extra.json (seconds)
```

Seeds are fixed. The tables of the technical appendix are generated by `paper/gen_tables.py` from the JSON file.
"Hard" (for the additive experiments) means: no subjectively SD-EF1 allocation is market-block-balanced for the identity market order.
